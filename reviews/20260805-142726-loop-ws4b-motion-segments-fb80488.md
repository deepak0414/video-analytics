## Findings

**1. Major — `src/va/provenance.py:81` — with motion-episodes selected, segment output now depends on the `motion_source` config, but `role_fingerprint("scene_detector")` does not fold that config in, so a motion_source change is a missed stale — the §6-b invariant this repo's provenance layer exists to forbid.** This range makes Role-1 output a function of where motion windows come from (backend model, `events_file`, NVR host/tz), yet the scene fingerprint hashes only the `scene_detector` spec. Scenario: WS4.b merges; a user follows the sidecar's own new warning ("real footage needs motion_source: lnr-eventlog") and switches the config; every previously-ingested epoch-placed chunk keeps segments built from the old (empty sidecar) motion data while `va stale` reports nothing — mixed old/new data shipped silently. I verified the fix exists **only on the stacked `loop/ws4c-nvr-chunk-source` branch** (its review round 5 rated this same defect major; the fold is in that branch's `provenance.py` with tests). Standing alone — which is exactly what `origin/main..HEAD` is — this branch ships the gap, and nothing in-range records that WS4.b must not merge without WS4.c. Safe path: cherry-pick the WS4.c fingerprint fold (and its tests) into this branch so it is self-consistent, or record in the digest/PR that WS4.b and WS4.c merge as an atomic batch (merge *order* alone doesn't guarantee WS4.c lands if it is later rejected).

**2. Minor — `src/va/roles/scene_detector.py:37` — the contract file promises spans "covering the video" while its newly listed motion-episodes backend deliberately returns gappy or zero spans.** The module docstring (line 4) and `detect`'s docstring both still state coverage; this same change adds motion-episodes to the backends list two lines above and documents zero-segments-for-a-quiet-chunk in COORDINATION.md. Scenario: another agent (this is a multi-agent repo; the web layer and Role-11 evidence assembly consume segments) codes to the Protocol's stated postcondition — e.g., assumes segment union spans the video for a timeline or coverage check — and is silently wrong on every security-profile chunk. Safe path: amend the contract text in this change to state coverage is backend-dependent (visual backends cover the video; motion-episodes yields episode windows, possibly none, plus the two full-span degraded modes).
