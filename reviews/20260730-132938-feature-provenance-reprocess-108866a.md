### Findings

**1. major — `src/va/pipeline/retrieval.py:216`** — The guard makes a fully-stale text index indistinguishable from a bad query, bypassing the designed lexical fallback. `index_populated` is `count() > 0`, and `count()` (`sharded.py:102`) ignores compatibility — so after an embedder switch without reingest (stub `hash` → `BAAI/bge-m3`, the exact scenario this feature targets), the semantic branch is chosen, `search_text` skips every shard and returns zero hits, and the `_gather_lexical` fallback plus its `ev.notes` entry (`retrieval.py:228-230`) never fire. `va ask` silently loses the entire text tier — no note in the evidence or answer, only a stderr log line — while a working, embedder-independent fallback sits right there. Pre-change this path crashed on the dim mismatch, so this is an improvement, but the plan's TAG-3 done-when promises "graceful degradation + a **surfaced note**", and nothing surfaces in the answer path. Safe path: treat "zero hits AND `store.skipped > 0`" (or zero *compatible* shards) as index-not-usable in `retrieval.py` — run the lexical fallback and append an `ev.notes` entry carrying the skipped count.

**2. minor — `src/va/storage/vector/sharded.py:34`** — An empty-but-tagged shard is misreported as an embedder mismatch. `index_text` with zero text rows (all four text roles empty — realistic on real footage: silent camera feed + captioner failure) persists `{"embedder": X, "dim": None}` (`text_index.py:88`, `numpy_flat.py:389` stamps `dim` from the empty array). `_compatible` then requires `meta.get("dim") == qdim`, so `None == 1024` skips the shard even when the embedder matches — every subsequent text search increments `skipped` and logs "reprocess them so they rejoin the index", a false alarm that reprocessing can never clear (re-indexing yields another empty shard), and it pollutes the `store.skipped` count COORDINATION.md tells the web agent to surface. Safe path: admit tagged shards with `dim is None` when the embedder matches (searching an empty shard is a no-op, `numpy_flat.py:74`), or exclude empty shards from the skipped count entirely.

**3. minor — `src/va/pipeline/query.py:27` (test gap, combination coverage)** — The guard wiring in `query()` and `search_text()` has zero coverage, and the stub config can't distinguish the two roles: both `visual_embedder` and `text_embedder` resolve to `"hash"`, so a cross-role mix-up (e.g. `query.py` passing `embedder_id("text_embedder")`) would pass the entire offline suite while zero-ing out every visual query under `run-siglip` (`siglip` ≠ `BAAI/bge-m3`). All guard tests drive `ShardedVectorStore` directly with hand-picked strings. Safe path: one offline test per query path that stamps shards with distinct fake ids and monkeypatches `embedder_id` (or the loaded config) to assert each path passes its own role's identity end-to-end.
