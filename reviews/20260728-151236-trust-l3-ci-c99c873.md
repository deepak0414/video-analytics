Two minor findings survive:

1. **`scripts/check_critical_paths.sh:23` — quotepath fail-open.** Git's default `core.quotepath=true` C-quotes any path containing non-ASCII bytes, wrapping it in double quotes (`"src/va/contracts/sch\303\251ma.py"`). The awk field then begins with a literal `"` character, so the `case "$f" in "$pattern"*` prefix match never fires and the file silently needs no label — the gate's one fail-open residue after the SIGPIPE/substring/rename fixes. It only affects files whose own names are non-ASCII (renames *of* existing ASCII critical files still show the unquoted source path, so they stay caught), which keeps it minor. `git -c core.quotepath=off diff -M --name-status …` closes it.

2. **`.claude/hooks/bash_guard.py:328,364` — two same-class gaps in the acknowledged speed bump.** httpie installs an `https` sibling binary not in the HTTP-client tuple, and `gh alias set m 'pr merge'` followed by `gh m 14` sails past the noun/action rules entirely (alias creation mentions no label or blocked noun; `m` matches nothing). D9 explicitly concedes this layer is non-exhaustive, so this is not a broken guarantee — but both routes are *easier* than the `gh auth token`+curl path rounds 4–5 chose to block, so they're the natural next spellings to add.
