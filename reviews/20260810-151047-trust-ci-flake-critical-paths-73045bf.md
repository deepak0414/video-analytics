**Findings — two minor, no critical or major.**

1. **`scripts/check_critical_paths.sh:36`** — `_cp_err=$(mktemp)` is the one unchecked command in a script whose entire thesis is "presume nothing." If `mktemp` fails, `_cp_err` is empty, the redirect `2>"$_cp_err"` fails before git runs, and the `||` branch prints `FAIL: cannot diff against '<sha>' — git said:` with an empty body followed by the shallow-clone hint. It fails closed, which is right — but it manufactures a fresh misdiagnosis of exactly the class this commit removes, and points the reader at the base sha when git never executed. One line fixes it: `_cp_err=$(mktemp) || { echo "FAIL: cannot create a temp file for git's stderr"; exit 1; }` (then re-copy into the plan mirror). Not hypothetical on a loaded runner: `test_large_changeset_does_not_fail_open` writes ~900 commits, and a full or read-only `/tmp` is a plausible CI condition.
