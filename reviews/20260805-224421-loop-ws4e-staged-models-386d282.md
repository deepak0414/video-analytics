**One new finding (minor).** The round-1 major's fix — the `del` releases — has zero test coverage. Stub adapters never register anything in `MANAGER` (only real adapters call `MANAGER.get`), so the offline suite can only assert that `clear()` *fires* at boundaries, never that weights actually become collectable. If a future refactor drops the `del embedder, detector` lines (they look like dead code to anyone who hasn't read the COORDINATION note), every test stays green and the unload silently becomes cosmetic again — exactly the round-1 regression. Safe path: a weakref-based test — monkeypatch one role getter to return a fake adapter that registers a sentinel object via `MANAGER.get` and binds it as `self._model`, take a `weakref` to the sentinel, and assert the ref is dead after the corresponding boundary under `unload-after-use`. That pins the local-release invariant the COORDINATION entry currently enforces by prose alone.
