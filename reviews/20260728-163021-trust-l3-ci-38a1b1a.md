The two surviving minors (both re-judged on the merits, both still real):

1. **`scripts/check_critical_paths.sh:23` — quotepath/whitespace fail-open.** Git's default `core.quotepath=true` C-quotes non-ASCII paths in double quotes, so the pure-bash prefix match never fires for them; additionally the `awk '{for (i=2;...)}'` split breaks any path containing whitespace into fragments that match no pattern. Scenario: a PR adds `src/va/contracts/schéma.py` (or a space-named critical file); the diff line starts with a literal `"`, the `case` prefix never matches, and the gate passes with no `human-reviewed` label. Fix: `git -c core.quotepath=off diff -M --name-status` (and NUL- or tab-aware parsing for the whitespace case).
2. **`.claude/hooks/bash_guard.py:328` — two sibling spellings outside the acknowledged speed bump.** httpie's `https` binary is missing from the HTTP-client tuple, and `gh alias set m 'pr merge'; gh m 14` bypasses all noun/action rules. D9 scopes this layer as defense-in-depth, so minor — but both routes are easier than the `gh auth token`+curl path the guard does block.

Neither blocks per the lifecycle (approve verdict tolerates minors); both are one-to-few-line fixes worth folding into the finalizing amend or the next trust PR.
