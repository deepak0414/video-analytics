**Findings that survived:**

1. **major — the docs-only exemption is an unreviewed channel into `reviews/disputes/` that the glob fix does not cover.** `commit-msg:33-34` and `pre-push:46-48` exempt branches touching only `.md`/`.txt` from all agent review, and `reviews/` is absent from the instruction-bearing list — safe before this commit, because agents could not write under `reviews/` at all. Now an agent can branch off main, write `reviews/disputes/evil.md` (allowed by the carve-out), commit with a plain subject (docs-only exemption passes), and push (pre-push skips review as docs-only; the append-only gate passes since it's an addition). That is the same end state round 2 rated major — agent-authored dispute text reaching main covered by no review, feeding a directory `agent-review.sh` now instructs every future reviewer to read and re-judge from — via a parallel channel. By the pre-push comment's own criterion ("files that shape agent behavior are NEVER inert docs"), `reviews/disputes/` now shapes reviewer behavior and belongs in the never-inert list in both hooks.

2. **minor — the round-2 major's fix shipped with zero regression-test coverage.** Nothing in `tests/test_trust_hooks.py` (or anywhere) asserts that a dispute file enters the review-scope hash or blocks the finalize shortcut; the as-built records manual verification only. WT.12 item 5 — codified in this same commit — demands plant-the-defect tests, and this repo has re-learned "a fix without a failing test is decoration" twice; reverting `:(glob,` would go green today.

3. **minor — carried over from round 3, still present and unfixed in HEAD:** the `ln` symlink-creation refusal (`bash_guard.py:318`) scans only non-flag tokens, so `ln -s --target-directory=reviews/disputes <target>` and `cp -s` still create a symlink inside the carve-out, contradicting matrix row 108's "blocked at BOTH ends".
