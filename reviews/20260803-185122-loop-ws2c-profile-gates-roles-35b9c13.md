## Full review

Review complete. This is round 5 of `loop/ws2c-profile-gates-roles` (HEAD `35b9c13`, one commit past the last-reviewed `c6e38db`). I verified both round-4 minors are genuinely fixed with real tests: the retry path now carries the recorded profile forward (`ingest.py:134`, `test_retry_of_failed_ingest_keeps_the_recorded_profile` — the assertion `transcript_lines == 0` proves the roles actually honored it, not just the record), and a missing recorded-profile yaml now degrades per-item in both `stale_report` (warn+skip) and `execute_reprocess` (failed entry), covered by `test_broken_profile_yaml_does_not_kill_stale_or_reprocess`. I ran the full offline suite myself: **559 passed / 2 skipped**.

The WS2.c done-conditions hold end-to-end (security profile → 0 transcript rows with the purge guarantee on retry; vocab override proven by driving stub detections, not just config plumbing; generic path byte-identical), the restamp uses the per-profile pinned config with the memoization asserted, test doubles were widened without weakening any assertion, and COORDINATION.md logs every shared-surface change with the web-agent behavior note. Two suspicions dissolved on inspection: `enabled: 0` sneaking past the core-role `is False` check is harmless (nothing consults `enabled` for core roles), and the tracker gate's short-circuit can't strand a disabled tracker because `frames_dets` gets a per-frame entry even with zero detections.

Three new minors, all on non-happy paths:

**1. Dependency-skipped roles read forever-stale with no remedy** (`src/va/pipeline/stale.py:51`). The `disabled` exclusion only checks `cfg.role(r).enabled`, but ingest also skips *dependents* of a disabled role (`ingest.py:296`, `366`). A profile disabling only `speech_to_text` leaves the diarizer enabled-but-skipped: unstamped, not excluded, so `recorded.get(r) != current[r]` reports it stale on every `va stale` run — and `va reprocess` advises `va reingest`, which re-skips it under the carried profile, forever. Same shape for `object_tracker` under a detector-only-disabled profile. The shipped `security.yaml` disables both speech roles so it dodges this, but the round-2 fix's stated goal ("not reported forever-stale") is defeated for any partial profile. Safe path: include the dependency closure in the `disabled` set (STT off → diarizer; detector off → tracker), or reject profiles at overlay-load that disable a parent without its dependent.

**2. The idempotent dedup no-op now crashes when a done video's recorded profile yaml is gone** (`src/va/pipeline/ingest.py:134`). The round-5 carry-forward runs *before* the probe and the done-check, so `va ingest <already-done-uri>` with no `--profile` resolves the row's recorded name and raises `FileNotFoundError` if that yaml was renamed — a plain re-run (e.g. a batch script re-invoking ingest idempotently) dies instead of printing `[already-ingested]`, while `stale`/`reprocess` were changed this same round to degrade gracefully for exactly this state. Explicit-arg validation on the dedup path is deliberate and fine; the carried recorded name is not an operator input. Safe path: for a carried (non-explicit) profile on a done row, catch the load failure and print the notice instead of raising.

**3. CLAUDE.md describes stale behavior the code no longer has** (`CLAUDE.md:243`). "skipped roles are not provenance-stamped, reading as stale, the safe direction" — but `stale.py` excludes profile-disabled roles from staleness (asserted by `test_security_profile_video_is_not_stale`), so under the disabling profile they do *not* read as stale. The next agent reading CLAUDE.md would expect `va stale` to list speech roles for a security-profile video. Safe path: reword to "excluded from staleness under the disabling profile; they read as stale only if the profile later re-enables them."

No contract breaks (schema v3 migrated and logged), no silently-hardcoded content, commit subjects are all provisional `need_agent_review:` and exempt from the clarity rule.

Verdict: **approve** — no critical or major findings; the three minors are cleanup-pass material.
